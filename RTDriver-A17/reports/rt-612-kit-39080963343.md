# RT ARM64 6.12: kit por kernel, Actions #39080963343

**El kit quedó publicado y verificado. No es un kernel, boot image ni `.ko`
universal para todos los dispositivos 6.12.** Contiene un perfil compilado
(Samsung A17 CZI4) y código/herramientas para construir y verificar otros
perfiles cuando se disponga de sus fuentes y salida de kernel exactas.

El workflow descarga el artefacto inmutable de la compilación real
[#39075095531](rt-port-build-39075095531.md), verifica el SHA del ZIP original,
los hashes individuales y los 15 archivos fuente frente al perfil de su
commit de compilación. Revisa los dos módulos como ELF ET_REL AArch64,
campos `.modinfo`, imports, CRCs básicos y extendidos y `Module.symvers`.
No vuelve a compilar el kernel ni modifica los binarios originales.

## Pruebas ejecutadas

Los 7 tests del kit pasaron en Actions. Incluyen el artefacto real, una
discrepancia introducida en el CRC del kernel, una tabla CRC extendida
alterada, otro release y la comprobación de un módulo sin firma ante una
configuración que exigiría firma. Las pruebas del selector rechazan otra
arquitectura, otra familia, otro release 6.12 y un archivo corrupto. Ninguna
de esas pruebas carga el módulo ni ejecuta las herramientas en Android.
El workflow reutiliza además la suite estática y los tests del port existentes.

`check_kernel.sh` solo lee el sistema y los archivos. Un perfil coincidente
devuelve `candidate_device_validation_required`, no compatibilidad probada.
Un kernel 6.12 sin perfil exacto devuelve `build_required_for_exact_kernel`.

## Pendientes y alcance

El único binario incluido es para SM-A175F CZI4. Para cada otro kernel hacen
falta fuentes, configuración, headers generados, toolchain y `Module.symvers`
propios, seguidos de un build y verificación reales. El builder Kbuild genérico
es una herramienta para ese trabajo; no demuestra que haya compilado para
otras variantes. Kleaf del fabricante y RANDSTRUCT requieren integración propia.

No se entrega una imagen universal del kernel ni se garantiza que coincidir
en el prefijo `6.12` permita cargar un módulo. No se alteraron localversion,
vermagic, firma, opciones de protección ni el teléfono. La aceptación de firma,
KMI del dispositivo y la integración APK siguen pendientes. El RT parcial
conserva ABI 3 y capacidades de código; INIT_KEY/GYRO_CONFIG no están
implementados y `original_rt_fully_verified` sigue en `false`.
